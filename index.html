تقرير الإنجاز الأسبوعي لمهارات وتقنيات البرمجة

خلاصة إنجاز أسبوع البرمجة

إعداد: لينا الدوسري - إدارة تقنية المعلومات
اللغات: C# | البرنامج: Visual Studio 2022

1. البرمجة الأساسية والمتقدمة (C# Fundamentals)

  • البرامج المستخدمة: بيئة التطوير المتكاملة Visual Studio 2022 وحزمة .NET 6 SDK[span_0](start_span)[span_0](end_span).
  • اللغات: لغة البرمجة **C#**.
  • أبرز المفاهيم: التمييز بين المصفوفات (Arrays) والمجموعات (Collections) لرفع كفاءة معالجة البيانات.
  • هياكل البيانات: تطبيق أساليب Generic List و Stack و Queue لسلامة وتنظيم الكود.
اللغات: C#, HTML, CSS | البرنامج: Visual Studio 2022

2. تطبيقات الويب (ASP.NET Core MVC)

  • البرامج المستخدمة: منصة Visual Studio 2022 لإدارة وتنسيق كود المشروع.
  • اللغات وتقنيات العرض: لغة **C#** للخدمات الخلفية، ولغات **HTML & CSS** للواجهات.
  • أبرز المفاهيم: تطبيق معمارية Model-View-Controller لتوزيع مهام النظام وسهولة الصيانة والتوسع.
  • الملفات المساعدة: استخدام Program.cs لحقن التبعيات و appsettings.json لسلاسل الاتصال.
اللغات: C#, JSON | الأدوات: Swagger / OpenAPI

3. واجهات البرمجة والخدمات (Web API & Swagger)

  • البرامج والأدوات: أداة Swagger UI المدمجة مع .NET 6 لاختبار واستعراض الـ Endpoints.
  • اللغات وصيغ البيانات: لغة **C#** لبناء الخدمات، وصيغة **JSON** لنقل البيانات بين الأنظمة.
  • أبرز المفاهيم: الربط بين الأنظمة المتباعدة والبرمجيات عبر طلبات بروتوكول HTTP بسرعة وأمان.
  • دورة معالجة الطلب: تنظيم التوجيه والحماية عبر تسلسل برمجيات الوسيط (Middleware).
اللغات: T-SQL | البرنامج: SQL Server & SSMS

4. إدارة قواعد البيانات (SQL Server 2019)

  • البرامج المستخدمة: خادم SQL Server Express 2019 وواجهة SQL Server Management Studio (SSMS).
  • اللغات المستخدمة: لغة الاستعلامات **SQL / T-SQL**.
  • أبرز المفاهيم: تصميم الجداول وربطها بالعلائق والمفاتيح (Primary & Foreign Keys).
  • العمليات التشغيلية: كتابة استعلامات السحب والفرز SELECT TOP 1000 لضمان استقرار وسرعة البيانات.

الخلاصة الموجهة للإدارة:

يغطي المسار منظومة تطويرية متكاملة ببدءاً من إتقان لغة C# وبيئة Visual Studio، مروراً بإنشاء تطبيقات الويب وخدمات الـ Web API بصيغة JSON، وصولاً لبناء وإدارة قواعد البيانات عبر SQL Server، مما يضمن القدرة على تنفيذ مشاريع مستقرة وقابلة للتوسع.
